# Agent Spec

## Overview
A lightweight Math & Calculator Assistant built with Google ADK (Python) using `agents-cli`. The agent assists users with everyday calculations, bill/tip calculations, and unit conversions (temperature, length, weight) using deterministic custom tools.

## Language
`python`

## Example Use Cases
1. **Tip & Bill Splitting**: User asks "Calculate a 20% tip on an $85 bill split between 4 people." Agent invokes `calculate_tip` and returns the tip amount, total bill, and amount per person.
2. **Unit Conversion**: User asks "Convert 75 miles to kilometers" or "What is 100 Celsius in Fahrenheit?". Agent invokes `convert_units` and returns the precise conversion.
3. **Basic Arithmetic**: User asks a multi-step calculation like "(145 * 12) + (250 / 5)". Agent computes the exact result.

## Tools Required
- `calculate_tip(bill_amount: float, tip_percentage: float = 18.0, split_by: int = 1) -> dict`: Computes total tip, grand total, and per-person breakdown.
- `convert_units(value: float, from_unit: str, to_unit: str) -> dict`: Converts length (miles, km, meters, feet), temperature (celsius, fahrenheit), and weight (kg, lbs).

## Constraints & Safety Rules
- Always use the provided tools for math calculations and unit conversions to avoid hallucinated numbers.
- Reject invalid inputs gracefully (e.g. `split_by <= 0`, negative bill amounts, unsupported unit pairs).
- Do not execute arbitrary code or shell commands.

## Success Criteria
- Deterministic and accurate results via tool execution.
- Agent successfully runs and responds locally via `agents-cli run`.
- Local interactive testing works via `adk web` or playground.

## Reference Samples
None required — this is a standalone single-agent setup using standard ADK function tools.

## Assumptions
- Target: Prototype mode (`--prototype`) with ADK Python template (`--agent adk`).
- Project directory name: `math-assistant`.
- Local execution and verification in `/config/Desktop/BuildWithGemini`.
